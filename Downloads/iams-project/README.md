# IAMS Attachment Portal: sign in / create account

Open `index.html` in a browser. No build step needed (Bootstrap loads from a CDN).

```
iams-project/
├── index.html
├── README.md
└── assets/
    ├── css/style.css   colours, hovers, layout
    └── js/app.js       view switching, show/hide password, strength meter, match check
```

Colours (top of `assets/css/style.css`):
- Primary: blue `--iams-blue`
- Secondary and hover: oceanic light blue `--iams-ocean`, `--iams-ocean-strong`
